Functions:

COUNT()
Returns the number of rows in a database table.

SUM()
Returns the total sum of a numeric column.

AVG()
Calculates the average of a set of values.

MIN()
Return the lowest value (minimum) in a set og not null values.

MAX()
Return the greatest value (maximum) in a set og not null values.
