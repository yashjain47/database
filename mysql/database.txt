"DATABASE"
A database is an organized collection of structured information or data.


"DBMS"
Database management system (DBMS) are software systems Used to store, retrieve and run queries on data.

FOR CRUD Operations
C   --> CREATE
R   --> READ
U   --> UPDATE
D   --> DELETE


Types of DBMS:

1.  Relational (SQL)
2.  Non-Relational (Non-SQL)


1.  Relational (SQL)
A relational database is a collection of data items with pre defined relationship between them, stored in the forms of table, rows and columns.
