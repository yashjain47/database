"Commands"
-----------------------------------

1.  show databases;
Used to show all databases.

2.  use <database_name>;
Used to use a particular database.

3.  show tables;
Used to show all the tables of a particular database.

4.  create database <database_name>;
Used to create a new database.

5.  create table <table_name>
    (
    column1 datatype,
    column2 datatype,
    column3 datatype,
    ......
    );
Used to create a new table

6.  insert into <table_name> (id,name,email,password,contact,address,dob,gender,status) values (1,"Yash","yashjain@gmail.com","yashjain4720","7878787812","Manesar","2000-10-04","M",1);
Used to insert single row data into the table 

7.  insert into <table_name> (column1,column2,column3,.....) values (value1,value2,value3,.....),(value1,value2,value3,.....),(value1,value2,value3,.....),...;
Used to insert multiple row data into the table 

8.  select column1,column2,.. from <table_name>;
Used to read/select columns from a table 

9.  select * from <table_name>;
Used to select all the columns from the table.

10. select */column1,column2..... from users where  <condition>;
Used to put the filter on the table we use "where" clause.
eg. select * from users where gender="F";

Conditions in where clause:
1.  =        (equals)
2.  !=       (not equals)
3.  >=       (greater than or equal to)
4.  <=       (less than or equal to)
5.  >        (greater than)
6.  <        (less than )

11. desc <table_name>;
Used to describe the table.



Types of SQL Commands:

1.	DDL (Data Definition Language) : create, alter, rename, truncate, drop
2.	DQL (Data query Language) : select
3.	DML (Data manipulation Language) : insert, update, delete
4.	DCL (Data control Language) : grant and revoke permisiion of the users.
5.	TCL (Transaction control Language) : start transaction, commit, rollback
