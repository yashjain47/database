1.  NOT NULL.
2.  UNIQUE.
3.  DEFAULT.
4.  CHECK.
5.  FOREGIN KEY.
6.  PRIMARY KEY.



AND Operator
select * from <table_name> where condition1 and condition2;

OR Operator
select * from <table_name> where condition1 or condition2;

NOT Operator
select * from <table_name> where not condition1;

IN Operator
select * from <table_name> where <column_name> in (value1,value2,....);


----------->>>>>>

LIKE Operator
select * from <table_name> where name like "s%";
The like operator used in where clause to search for a specified pattern in a column.

--> the percentage sign (%) represents zero, one or multiple character.
--> the underscore sign (_) represents one single character. 

like "a%"   --> starts with 'a'
like "%a"   --> ends with 'a'
like "%or%" --> Having 'or' in any position
like "_r%"  --> Having 'r' in second position
like "a_%"  --> starts with 'a' and are at least 2 characters in length
like "a__%" --> starts with' a' and are at least 3 characters in length
like "a%o"  --> starts with 'a' adn ends with 'o'.


----------->>>>>>
works for numbers only not for string.

BETWEEN Operator
select * from <table_name> where <column_name> between value1 and value2;
select * from students where age between 20 and 25;

NOT BETWEEN Operator
select * from <table_name> where <column_name> not between value1 and value2;
select * from students where age not between 20 and 25;


----------->>>>>>
Used to sort for ascending and descending order of the data.

ORDER BY Operator
select * from <table_name> order by <column_name> ASC|DESC;


----------->>>>>>
Used to remove/not show the duplicate data.

DISTINCT Operator
select distinct <column_name> from <table_name>;


----------->>>>>>

IS NULL Operator
select * from <table_name> where <column_name> is null;

IS NOT NULL Operator
select * from <table_name> where <column_name> is not null;


----------->>>>>>

LIMIT Operator
select * from <table_name> limit <number_to_limit_by>;

If you want to limit, the number of results that are returned you can simply use the LIMIT command with several rows to LIMIT by.


OFFSET Operator
select * from <table_name> limit <number_to_limit_by> offset <number_of_rows_to_skip>;

You can also specify an offset from where to start the returning data.
