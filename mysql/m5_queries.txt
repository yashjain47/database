1.  SELECT
    select * from <table_name>; 

2.  INSERT
    insert into <table_name> (column1,column2,column3,.....) values (value1,value2,value3,.....),(value1,value2,value3,.....),(value1,value2,value3,.....),...;

3.  UPDATE
    update <table_name> SET <field1> = <new_value1>,<field2> = <new_value2>,.. where <condition>;

4.  DELETE
    delete from <table_name> where <condition>;

5.  ALTER
    alter table <table_name> <> <perimeter>;
    ALTER TABLE Persons ADD PRIMARY KEY (ID);

Commit  & Rollback

start --> (CUD) --> commit --> rollback
in Insert , delete , update
 
If any wrong CUD Operations happens then we can rollback to it (just like revert the Operations).

if Commits happen then we can not rolllback it.
if rollback happen then its obviously not committed.

CUD = Create,update,delete


----------->>>>>>

Primary Key and Foreign Key

Primary Key always contains unique data.
It cannot be null.
There must be single primary key in a table.

Foreign key is used to link two tables.
Foreign key in one table (child table) is used to point PRIMARY KEY in another table (Parent Key).

FOR PRIMARY KEY AND FOREIGN KEY


CREATE TABLE Persons (PersonID int NOT NULL PRIMARY KEY, LastName varchar(100) NOT NULL, FirstName varchar(100) NOT NULL, Age int NOT NULL);

select * from Persons;
+----------+----------+-----------+-----+
| PersonID | LastName | FirstName | Age |

|        1 | Jain     | Yash      |  23 |
|        2 | Huesen   | Van       |  32 |
|        3 | bently   | John      |  25 |
+----------+----------+-----------+-----+


CREATE TABLE Orders (OrderID int NOT NULL,OrderNumber int NOT NULL,PersonID int,PRIMARY KEY (OrderID),FOREIGN KEY (PersonID) REFERENCES Persons(PersonID));
