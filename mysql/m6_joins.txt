1.  INNER JOIN

MySQL Inner Join is used to returns only those results from th tables thta match the specified condition and hide the other rows and columns.
MySQL assumes it as a default Join, so it is optional to use the Inner join keyword with the query.

Syntax:
select <column_name>/* from <table1_name> inner join <table2_name> on <condition1>;

Examples:
select * from Persons inner join Orders on Persons.PersonID = Orders.PersonID;
+----------+----------+-----------+-----+---------+-------------+----------+
| PersonID | LastName | FirstName | Age | OrderID | OrderNumber | PersonID |

|        1 | Jain     | Yash      |  23 |       4 |       24562 |        1 |

select * from Orders inner join Persons on Persons.PersonID = Orders.PersonID;

2.  LEFT JOIN

MySQL Left join returns all the record from the left table (table 1), and the mathed records from the right table (table2).

Syntax:
select <column_name>/* from <table1_name> left join <table2_name> on <condition1>;

Example:
select * from Persons left join Orders on Persons.PersonID = Orders.PersonID;
+----------+----------+-----------+-----+---------+-------------+----------+

3.  RIGHT JOIN

MySQL Right join returns all the record from the Right table (table 2), and the mathed records from the Left table (table1).

Syntax:
select <column_name>/* from <table1_name> Right join <table2_name> on <condition1>;

Example:
select * from Persons right join Orders on Persons.PersonID = Orders.PersonID;

4.  CROSS JOIN

MySQL Cross join produces a result set which is the number of rows in the first table multiplied by the number of rows in the second table if no where clause is used along with cross join.

This kind of result is called Cartesian Product.

Syntax:
select <column_name>/* from <table1_name> cross join <table2_name>;
        --or--
select <column_name>/* from <table1_name> cross join <table2_name> on <condition1>;
